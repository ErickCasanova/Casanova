# Casanova

Official website of **Casanova**, a tango blues artist based in Tijuana, Mexico.

Casanova started as a member of the band The Stone Avenue and went solo to write, record and produce his own music. Every track is produced by Casanova himself, with a new song released every month.

**Live site:** <https://casanovaofficial.vercel.app>

**Listen:** [Spotify](https://open.spotify.com/artist/3sPLJZEXN9fogz9YVqB6CG) · [YouTube](https://www.youtube.com/@casanovaofficialmusic) · [TikTok](https://www.tiktok.com/@casanovaofficiall)

---

## About the code

Built with Next.js 14, React 18, TypeScript and Tailwind CSS, using shadcn/ui components. Deployed on Vercel, which rebuilds the site on every push to `main`.

| Folder | What's in it |
| --- | --- |
| `app/` | Page layout, global styles and the home page |
| `components/` | The site's sections: hero, about, timeline, discography, music player, live performances, contact |
| `components/ui/` | Shared shadcn/ui building blocks |
| `public/` | Photos and images |

### Run it locally

```bash
npm install
npm run dev
```

Then open <http://localhost:3000>.
